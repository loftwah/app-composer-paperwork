# Security

PDFs/signatures are local session data. No server upload or content analytics. Scripts, workers, fonts and PDF rendering resources are bundled. CSP limits scripts/requests to this origin and prohibits arbitrary frames, objects and form submission. Embedded PDF actions are never executed and export removes actions. File, page, image, widget, ink and render limits bound ordinary inputs; this is not a claim that every malformed PDF is harmless.

Report vulnerabilities privately through the repository owner's GitHub security contact. Do not include real documents, signatures, credentials or personal data in public reports. XFA, encrypted and already certificate-signed documents are unsupported.
