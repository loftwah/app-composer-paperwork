# Accessibility

Native buttons, fields and selects, visible keyboard focus, labelled tools, status announcements and light/dark themes are provided. Keyboard shortcuts and object movement/resizing are documented in Help. Text/ticks/signatures have a keyboard placement alternative. The PDF canvas itself does not expose original page prose as selectable HTML; full document reading with a screen reader and physical mobile keyboards have not been qualified. Report a reproducible issue with synthetic data only.
