# Required design entry path — Paperwork

Read AGENTS.md and this app's product/design/privacy requirements. This rule is NOT Impeccable, an installer or proof of use. MP already requires the actual skill without reminders.

Resolve the actual harness and loaded upstream SKILL.md, skill/CLI/engine and project/global/plugin precedence. Read official setup/release guidance; install/update via the supported route with reviewed versions, preserving customisations and backups outside discovery. The trusted local Woodhouse checkout supplies `scripts/impeccable-project.mjs` and `docs/IMPECCABLE.md`; no moving remote script execution. Prove fresh-session discovery and supported hooks actually firing; respect real trust approvals.

Run the resolved context launcher once in this repository for the target. Read PRODUCT.md, DESIGN.md, surface briefs and accepted references. Reuse known owner decisions and follow upstream fallback honestly on launcher failure. Read relevant shape/new-work, critique, audit and targeted polish/adapt/harden/typeset/layout/clarify guidance and the craft floor before edits. Detector-only checks are insufficient.

Inspect actual local form-fill, drawing/signature, navigation/zoom and export tasks using synthetic documents. Check touch/pointer/keyboard, focus, small-screen controls, legibility, overflow, empty/loading/error/recovery and reduced motion. Preserve document integrity and browser-local processing. Do not upload private PDFs, form contents or signatures to a model/provider or publish them in evidence. Verify the exported result, not just toolbar appearance. Fix material findings and reinspect.

Record tool/harness/source/target, context/playbooks, findings, changes or justified no-change, rendered interactions and limits in the app's existing issue/PR/evidence. Setup, discovery, use, remediation, main and production are separate. Runtime work requires main AND verified authorised production; tooling-only work needs main and focused checks. Preserve independent ownership.
